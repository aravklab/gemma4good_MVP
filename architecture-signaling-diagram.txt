================================================================================
MERMAID — sequenceDiagram (single turn, simplified)
================================================================================

sequenceDiagram
  participant S as Student / Browser
  participant A as Streamlit app.py
  participant O as Ollama
  participant P as Persona reply

  S->>A: User message (text or post-STT)
  A->>A: compile_evaluator_prompt(...)
  A->>O: Evaluator chat (JSON mode)
  O-->>A: {classification}
  A->>A: build_state_directive(...)
  A->>A: compile_pip_prompt(directive)
  A->>O: Persona chat (natural language)
  O-->>A: Persona assistant text
  A->>A: Append to messages; rerun
  A-->>S: Rendered chat + UI
